# Pinto — 忘れる前に、ピン✓

## 仕様

- アプリ名は、 **Pinto（ピント）** です。名称・配色・アイコンは変更できます。
- 初版は、Galaxy S25で個人利用する前提の端末内完結版です。アカウント登録・広告・解析・独自の通信処理はありません。
- 通知は電池を過度に消費しないAndroid標準の方式を使うため、端末の省電力状態によって数分ずれる場合があります。
- 同梱APKは個人テスト用のデバッグ署名版です。Google PlayやGalaxy Storeで配布する場合は、正式なリリース署名とストア登録が別途必要です。

## 実装した機能

- **自分で決める優先度**: 高・中・低の3段階。編集画面と一覧メニューの両方から変更可能
- **毎日の繰り返し**: 開始日時と終了日を指定。終了日を含めて毎日繰り返し
- **翌日分を自動追加**: 今日の分を完了すると、同じ時刻・優先度・通知設定で翌日分を1件だけ作成
- **やり忘れを保持**: 未完了の回は翌日になっても消さず、期限切れとして残す
- **見落としにくい並び順**: 期限を優先し、同じ期限なら高→中→低で表示
- **期限通知**: 期限ちょうど・10分前・1時間前・1日前から選択
- **通知から処理**: 「10分後」と「完了」を通知上で操作可能
- **再起動後も通知を復元**: 端末再起動時に未完了タスクを再スケジュール
- **今日・これから・すべて・完了**: 迷いにくい4つの表示切替
- **検索**: タスク名とメモを横断検索
- **進捗表示**: 今日の残り件数と完了率をホーム上部に表示
- **整理したホーム画面**: 進捗→表示切替→検索→件数付き一覧の順に配置
- **状況別の空画面**: 予定追加・検索解除・今日へ戻る操作を、その場に必要な1つだけ表示
- **端末内保存**: SQLiteへ保存。アプリを閉じても保持

## 優先度の見え方

| 優先度 | 色 | 想定する使い方 |
|---|---|---|
| 高 | 赤 | 今日中・忘れると困る |
| 中 | 緑 | 通常の予定（初期値） |
| 低 | グレー | 余裕があるときに行う |

## 操作メモ

- タスクをタップ: 内容・期限・通知・優先度を編集
- 左のチェック: 完了／未完了を切り替え
- 右の `⋮`: 編集、優先度の即変更、削除
- 右下の「＋ 新しい予定」: メモ・優先度・期限・通知・繰り返しを設定して登録
- 毎日の予定: 編集画面で `毎日` を選び、開始日時と終了日を設定

## 毎日繰り返しの動作

1. 「予定を追加」で予定日時を設定します。この日時が繰り返しの開始です。
2. 「繰り返し」で「毎日」を選択します。
3. 終了日を設定します。終了日当日の分も作成対象です。
4. 当日分を完了すると、翌日分が自動追加されます。

一度に全日程を作らず、常に次の1件だけを用意します。半年・1年の期間を指定しても一覧や通知が重くなりにくい設計です。途中で止める場合は、現在の繰り返しタスクを「繰り返さない」に変更するか削除します。

## データについて

タスクはアプリ専用のSQLiteデータベースに保存されます。Pinto自体はネットワーク権限を持ちません。Androidのバックアップ設定が有効な場合は、OS標準のバックアップ／端末移行対象になることがあります。アプリを削除すると、復元できない場合があるためご注意ください。
