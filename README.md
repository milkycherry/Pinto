# Pinto

## 概要

- アプリ名は、 **Pinto（ピント）** です。
- Todoリストを自分で作成し、タスクを管理するためのアプリケーションです。
- 作成者自身が忘れっぽいところがあるので日々のタスクを管理したいと思い、作成しました。

## 実装した機能

- **自由な内容で登録**: 高・中・低の3段階。編集画面と一覧メニューの両方から変更可能。期限を優先し、同じ期限なら高→中→低で表示
- **毎日の繰り返し**: 開始日時と終了日を指定。終了日を含めて毎日繰り返し
- **翌日分を自動追加**: 今日の分を完了すると、同じ時刻・優先度・通知設定で翌日分を1件だけ作成
- **期限通知**: 期限ちょうど・10分前・1時間前・1日前から選択 
- **検索**: タスク名とメモを横断検索
- **表示**: 今日の残り件数と完了率をホーム上部に表示。進捗→表示切替→検索→件数付き一覧の順に配置
- **端末内保存**: SQLiteへ保存。アプリを閉じても保持

## 優先度の見え方

| 優先度 | 色 | 想定する使い方 |
|---|---|---|
| 高 | 赤 | 今日中・忘れると困る |
| 中 | 緑 | 通常の予定（初期値） |
| 低 | グレー | 余裕があるときに行う |

## 操作メモ

- 右下の「＋ 新しい予定」: メモ・優先度・期限・通知・繰り返しを設定して登録
- 毎日の予定: 編集画面で `毎日` を選び、開始日時と終了日を設定
- タスクをタップ: 内容・期限・通知・優先度を編集
- 左のチェック: 完了／未完了を切り替え
- 右の `⋮`: 編集、優先度の即変更、削除

## 毎日繰り返しの動作

1. 「予定を追加」で予定日時を設定します。この日時が繰り返しの開始です。
2. 「繰り返し」で「毎日」を選択します。
3. 終了日を設定します。終了日当日の分も作成対象です。
4. 当日分を完了すると、翌日分が自動追加されます。

一度に全日程を作らず、常に次の1件だけを用意します。半年・1年の期間を指定しても一覧や通知が重くなりにくい設計です。途中で止める場合は、現在の繰り返しタスクを「繰り返さない」に変更するか削除します。

## データについて

タスクはアプリ専用のSQLiteデータベースに保存されます。Pinto自体はネットワーク権限を持ちません。Androidのバックアップ設定が有効な場合は、OS標準のバックアップ／端末移行対象になることがあります。アプリを削除すると、復元できない場合があるためご注意ください。
